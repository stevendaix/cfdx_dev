# EXT-NACA0012 — NACA 0012 external-flow qualification

Reference: low-Re laminar NACA 0012 literature for the first incompressible subcase; the NASA/TMR/Ladson turbulent case remains a separate future campaign.

Required evidence: chord=1, frozen laminar Reynolds number and angle of attack, body-fitted 2-D mesh generated by Python without Gmsh, no-slip airfoil, controlled farfield, pressure/lift/drag extraction, independent conservation, convergence and three mesh levels. Force components must be computed from the CFDX solution rather than an oracle.

**Current status:** READY for mesh/solver implementation. PR #443 now provides a deterministic Python-generated body-fitted O-grid in CFDX-HDF5. The mesh interchange path is covered by the strict HDF5 schema reader; quantitative PASS remains blocked until the laminar solver, force/moment integration, mesh refinement and literature comparison are executed.
