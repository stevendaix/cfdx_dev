# EXT-NACA0012 — NACA 0012 external-flow qualification

Reference: Ladson (1988), experimental NACA 0012 data.

Canonical first subcase: chord 1, incompressible laminar baseline; freeze Reynolds number and angle of attack before quantitative PASS. Record C-grid/O-grid topology, farfield distance, wall resolution, Cp/CL/CD/Cm, conservation and three mesh levels.

**Current status:** PLANNED. The repository does not yet expose a complete external-airfoil solver driver suitable for this qualification. This document is a contract, not validation evidence.
