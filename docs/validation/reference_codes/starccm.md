# Siemens Simcenter STAR-CCM+ reference dossier

## Evidence scope

Public Siemens documentation is supplemented only by publicly accessible technical material when the proprietary mathematical contract is not exposed in sufficient detail. Such rows are marked with the weaker evidence class.

## Relevant documented capabilities

The public STAR-CCM+ solver documentation lists:
- finite-volume segregated and coupled flow solvers;
- SIMPLE, PISO and SIMPLEC solution algorithms;
- algebraic multigrid;
- first/second-order upwind and central-differencing convection options;
- bounded central and hybrid higher-order convection options;
- first- and second-order implicit time discretisation.

Siemens-hosted documentation is also available for the solver families and numerical options.
