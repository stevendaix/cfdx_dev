# N9-S8 — NASA/TMR NACA 0012 laminar external-flow campaign

## Scope

N9-S8 is the first N9 external-flow benchmark. It remains **laminar** and
incompressible: the purpose is to qualify pressure–velocity robustness, not
turbulence modelling.

Frozen first population: NACA 0012, chord c=1, U_inf=1, rho=1, Re_c=1000,
alpha=0 deg, nu=1e-3, steady incompressible flow, no-slip airfoil and uniform
free-stream velocity at the far field.

At alpha=0 the symmetric geometry provides an independent sanity gate:
converged lift must remain close to zero without imposing Cl=0 in the solver.

## Independent mesh source

N9-S8 uses the public NASA Turbulence Modeling Resource NACA 0012 C-grid
family. The mesh is **not generated by CFDX** for the qualification population.

Sources:
- NASA TMR: https://turbmodels.larc.nasa.gov/naca0012_grids.html
- NASA archive: https://www.nasa.gov/wp-content/uploads/2026/02/naca0012-grids.zip

The importer is scripts/import_tmr_naca0012.py. It is deliberately offline:
validation meshes must be supplied by a controlled environment and CI must
never download a mesh implicitly.

| Level | NASA/TMR grid | CFDX use |
|---|---:|---|
| coarse | 225 x 65 | debug/refinement |
| medium | 449 x 129 | primary N9-S8 |
| fine | 897 x 257 | mesh-convergence check |

The importer preserves the C-grid topology and records source/grid metadata
in HDF5. Wake-cut faces remain explicit boundaries.

## Scientific reference

Swanson & Langer (2016), *Steady-state laminar flow solutions for NACA 0012
airfoil*, documents laminar NACA 0012 cases as tests of numerical accuracy,
stability and convergence. Their published cases are compressible
(M=0.5, Re=5000 and M=0.8, Re=500), so those coefficients are **not** used as
an oracle for this incompressible Re=1000 case.

Independent low-Re literature documents Re=1000 NACA0012 behaviour and
supports low-angle two-dimensional laminar flow as a numerical benchmark.
The first N9 population therefore freezes alpha=0 and avoids the known
higher-angle vortex-shedding regime.

## N9 algorithm matrix

The same six N9 pressure–velocity families must run on the **same imported
mesh, physics and convergence contract**. No algorithm-specific mesh or
relaxed tolerance is permitted.

Retain for every algorithm:
- nonlinear history;
- pressure/momentum linear iterations;
- independently recomputed true residuals;
- continuity/mass imbalance;
- force balance;
- Cd, Cl, Cm;
- pressure and viscous drag;
- Cp(x/c);
- runtime/iterations;
- final numerical-selection report.

A plausible coefficient with failed conservation/residual gates is a failure.

## Mesh-convergence gates

Required evidence:
- valid topology and positive cell volumes;
- complete boundary patches;
- converged nonlinear solve on all three levels;
- independent continuity check;
- stable Cd under refinement;
- symmetry gate on Cl;
- Cp convergence;
- refinement trend recorded before physical comparison.

A formal observed order is reported only where the QoI/error definition makes
it mathematically meaningful.

## Validation status

This PR establishes the **external NASA/TMR mesh path and N9-S8 contract**.
It does not claim a physical validation PASS.

The current case is therefore **NOT QUALIFIED** until CFDX has actually
executed the imported 225x65, 449x129 and 897x257 meshes with the complete
six-method N9 matrix and retained Total Validation evidence.

## Total Validation

The contract test is registered in the validation population. The expensive
solver campaign belongs to the long/Total Validation population once the
controlled TMR meshes are materialized. A quick geometry/contract pass is
never promoted to numerical qualification.
