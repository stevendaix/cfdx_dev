# N6 — Production dual-time field integration\n\n## Scope\n\nPR: production field-level integration of the dual-time contracts introduced by N6.\n\nThis layer connects:\n- DualTimePhysicalScheme (backward Euler / BDF2);\n- the deterministic pseudo-time driver;\n- DualTimeFieldHistory physical-time history;\n- embedded BE/BDF2 temporal-error estimation;\n- physical-step acceptance/rejection;\n- admissibility gating;\n- bounded physical timestep proposal.\n\nThe implementation is deliberately field-level and backend-neutral. It does not claim that the complete incompressible Navier–Stokes solver has been converted to dual-time stepping.\n\n## Physical-time lifecycle\n\nFor each requested physical step:\n1. Clamp the requested dt to configured bounds.\n2. Use the accepted field at t^n and, after the first accepted step, the stored field at t^(n-1).\n3. Solve the physical residual in pseudo-time.\n4. Use BDF2 once two accepted physical states exist.\n5. Bootstrap the first step with backward Euler.\n6. Solve an embedded backward-Euler step for temporal-error estimation.\n7. Evaluate temporal-error, nonlinear-convergence and physical-admissibility gates.\n8. Commit U^(n+1) to history only after all gates pass.\n9. Propose the next physical timestep using normalized temporal error and method order.\n\nA rejected step never modifies the accepted history.\n\n## Residual contract\n\nThe field RHS callback represents the spatial/semi-discrete operator:\n\n    dU/dt = RHS(U)\n\nThe dual-time residual is therefore:\n\n    BE:   R = U - U^n - dt RHS(U)\n    BDF2: R = 3/2 U - 2 U^n + 1/2 U^(n-1) - dt RHS(U)\n\nPseudo-time updates use:\n\n    U^(k+1) = U^k - dtau R(U^k)\n\nThe existing deterministic pseudo-time driver remains the single implementation of the iteration loop.\n\n## Verification\n\nThe unit test verifies:\n- BE bootstrap;\n- physical-history commit;\n- BDF2 activation after the first accepted step;\n- pseudo-time convergence;\n- temporal-error diagnostics;\n- decay of the manufactured scalar ODE dU/dt = -U;\n- physical admissibility rejection;\n- rollback semantics: a rejected step leaves the last accepted state unchanged.\n\n## Deliberate scope boundary\n\nThis PR does not claim:\n- direct integration into steady_incompressible_solver.h;\n- production Navier–Stokes transient boundary-condition orchestration;\n- pressure-velocity dual-time coupling;\n- HDF5 transient checkpoint schema changes;\n- restart qualification for dual-time histories;\n- full transient MMS qualification of the Navier–Stokes solver.\n\nThose remain follow-up work. Keeping this boundary explicit prevents a generic field adapter from being mistaken for complete transient CFD qualification.
