# VMFL036 — Literature-aligned sphere case at Re=100

This file defines the canonical Re=100 CFDX sphere benchmark used by the engineering qualification programme.

- D = 1 m; rho = 1 kg/m³; U = 1 m/s; mu = 0.01 Pa.s; Re = 100.
- Reference projected area: A = pi D²/4.
- Literature reference: Cd = 1.0895; derived reference drag = 0.4278456495 N.
- Model: steady, incompressible, laminar.
- Geometry: body-fitted sphere in a finite external-flow domain.

The reference Cd and force are **oracles only**. CFDX must independently compute pressure drag, viscous drag and total drag from the sphere-wall traction integral.

## Required evidence

The solver test must retain:

1. mesh generation/import and topology diagnostics;
2. nonlinear convergence and true continuity/momentum diagnostics;
3. pressure, viscous and total drag;
4. Cd decomposition and the independent projected-area normalization;
5. coarse/medium/fine refinement before a literature-accuracy PASS;
6. runtime and CTest/CI evidence.

The present executable gate establishes a reproducible physical CFD run. It does **not** claim literature-accuracy PASS until the mesh/domain study is complete.

## Reproducibility

The body-fitted mesh is generated by `scripts/generate_vmfl036_mesh.py`. The executable prints `VMFL036_MESH`, `VMFL036 RESULT` and `VMFL036 DRAG` markers so the physical result is retained in CI logs.
