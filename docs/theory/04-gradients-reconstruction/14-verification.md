# 14. Verification

Verification asks whether the implemented numerical method correctly realizes its mathematical specification.

The gradient campaign should include:

1. constant-field preservation;
2. linear-field exactness where theoretically expected;
3. quadratic smooth-field accuracy;
4. refinement studies;
5. distorted and polyhedral mesh tests;
6. boundary-stencil tests;
7. conditioning and rank-deficiency diagnostics;
8. deterministic regression tests.

A verification record should identify the method, mesh, field, reference solution, norm, observed order, software revision and execution configuration.

The Theory chapter explains the mathematics and experimental rationale. Authoritative qualification status and evidence remain in the V&V domain.
