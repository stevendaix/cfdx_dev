# CFDX Documentation

CFDX documentation is organised as four complementary domains:

- **Theory** — CFD and numerical methods as a mathematical course;
- **User** — supported workflows and practical usage;
- **Developer** — software architecture and implementation contracts;
- **V&V** — executable evidence, validation and qualification records.
