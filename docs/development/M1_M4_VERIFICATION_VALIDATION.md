# M1-M4 Verification and Validation Plan\n\nCFDX separates verification (mathematical/numerical implementation correctness) from validation (agreement with physical/reference data). A model can be implemented consistently and still require physical validation.\n\n## M1 — Incompressible\n\n### Unit verification\n- coefficient positivity and dimensional invariants\n- pressure-velocity relaxation\n- Rhie-Chow zero-gradient and linear-pressure invariants\n- pressure-correction matrix symmetry/conservation\n- mass imbalance per control volume\n\n### Analytical cases\n1. Plane Poiseuille: exact velocity profile, exact flow rate, wall no-slip, pressure-gradient forcing, L2/Linf errors and mesh-refinement order.\n2. Lid-driven cavity: centerline profiles, global mass imbalance, kinetic-energy residual and pressure-reference invariance.\n3. Taylor-Green vortex: analytical transient decay and temporal-order verification.\n\nAcceptance is based on quantitative error norms and convergence rates, not only solver residuals.\n\n## M2 — Turbulence\n\n### Model verification\n- k-epsilon production, diffusion and destruction terms\n- SST blending functions and eddy-viscosity limiter\n- wall-law asymptotics\n- positivity of k, epsilon and omega\n- bounded turbulent viscosity\n\n### Validation\n- fully developed turbulent channel\n- flat-plate zero-pressure-gradient boundary layer\n- SST comparison against NASA TMR reference data where applicable\n\nThe exact turbulence-model variant, constants and wall treatment must be pinned in each benchmark.\n\n## M3 — Thermal / CHT\n\n### Verification\n- pure-conduction manufactured solutions\n- advection-diffusion manufactured solution\n- energy conservation\n- interface flux continuity\n- transient diffusion convergence\n- positivity/maximum-principle checks where applicable\n\n### CHT validation\n- 1D two-material slab with analytical thermal resistance\n- conjugate channel benchmark\n- multi-region energy conservation\n\n## M4 — Radiation\n\n### Verification\n- Stefan-Boltzmann blackbody law\n- gray-body limiting cases\n- view-factor closure\n- view-factor reciprocity\n- DOM quadrature normalization\n- P1 source-term sign and limiting cases\n\n### Validation\n- two-surface enclosure\n- canonical gray enclosure\n- participating-medium benchmark\n- radiation/energy coupled balance\n\n## Required gates\n\nEvery M1-M4 solver must pass compilation with warnings enabled, unit tests, sanitizer tests, manufactured-solution tests, analytical benchmarks, conservation checks, mesh-refinement studies, restart/reproducibility tests, and serial/parallel equivalence where MPI is enabled.\n\nA solver is not considered complete merely because its residual reaches a tolerance. Residual convergence, conservation, discretisation error and comparison with an independent reference are all required.
