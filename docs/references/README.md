# References and scientific sources

This directory contains the maintained scientific bibliography used by the Theory, Developer and V&V documentation.

## Bibliography

The canonical BibTeX database is:

`docs/references/bibliography.bib`

References should be cited for:

- governing equations and physical laws;
- finite-volume and reconstruction methods;
- linear algebra and preconditioning;
- turbulence and radiation models;
- verification/validation methodology;
- benchmark definitions and published reference data.

## Source-selection rules

Prefer the original paper, standard textbook, official technical report, or authoritative software documentation. Record enough bibliographic information to make the source independently identifiable.

A literature result is not a CFDX result. Published benchmark values define an oracle or comparison target; they do not constitute evidence that CFDX reproduced that result.

## Documentation provenance

When a chapter contains an implementation claim, pair the scientific reference with an exact repository source mapping and, where applicable, executable verification evidence.
