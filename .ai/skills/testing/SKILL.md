# Procedure

1. Map the changed behavior to existing tests.
2. Add a focused test when coverage is missing.
3. Run the narrowest relevant test first.
4. Run the required broader gate.
5. Preserve failing evidence and classify failures as product, test, environment or infrastructure issues.

# Numerical testing

Residual convergence alone is not sufficient when an analytical, MMS, conservation, boundedness or refinement measurement is required.

# Rules

Never change tolerances or remove tests solely to turn a failure into a pass.
