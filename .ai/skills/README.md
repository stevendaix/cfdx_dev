# CFDX AI Skills

Skills describe reusable capabilities. They are not autonomous agents and must not become independent sources of repository state.

Every skill should define purpose, scope, activation conditions, exclusions, required context, procedure, available tools, expected output, validation/evidence requirements, failure handling and authoritative references.

Initial families include repository navigation, code search, architecture, C++, Python, CMake, HDF5, testing, CI, code review, numerical methods, FVM, mesh, boundary conditions, linear solvers, turbulence, multiphysics, temporal discretisation, validation, GUI, TUI and documentation.
