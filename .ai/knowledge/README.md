# CFDX AI Knowledge

This directory contains compact AI-oriented entry points into authoritative CFDX knowledge. It should not duplicate the complete documentation tree.

Each topic should identify the CFDX concept, authoritative source files, relevant implementation locations, tests/validation and important constraints.

Knowledge families: architecture, numerical, validation, GUI, TUI, workflows and references.

If knowledge conflicts with current code or authoritative documentation, the agent must flag the conflict and prefer current repository evidence after investigation.
