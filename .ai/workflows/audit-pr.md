# Workflow: Audit a CFDX PR

1. Read the PR description and linked issue.
2. Inspect the complete diff.
3. Locate affected implementation and public APIs.
4. Locate tests and validation cases.
5. Inspect CI status and relevant workflow definitions.
6. Check documentation consistency.
7. For numerical changes, inspect mathematical/discrete formulation and V&V evidence.
8. Separate implemented, tested, verified, validated and qualified claims.
9. Report findings with concrete evidence and remaining gaps.

Do not approve a change merely because CI is green.
