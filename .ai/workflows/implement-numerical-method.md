# Workflow: Implement a CFDX Numerical Method

1. Define the mathematical method and intended scope.
2. Identify authoritative literature/reference implementations.
3. Locate current CFDX operators, data structures and extension points.
4. Determine conservation, consistency, stability and boundedness requirements.
5. Define verification tests and expected convergence behavior.
6. Implement the smallest coherent change.
7. Run unit/regression tests.
8. Run manufactured-solution or analytical/reference benchmarks as applicable.
9. Inspect convergence and error trends, not only residuals.
10. Update theory/developer/V&V documentation.
11. Review the diff independently.
12. Report qualification status separately from implementation status.
