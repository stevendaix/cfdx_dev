# Workflow: Implement a CFDX Feature

## 1. Understand

Read the issue completely. Identify acceptance criteria, non-goals and related issues, PRs and documentation.

## 2. Search

Inspect relevant source, public APIs, tests, validation cases and documentation. Use dependency/impact information when available.

## 3. Plan

Identify affected modules, API/data-model changes, tests, validation, documentation and risks.

## 4. Implement

Make the smallest coherent change satisfying the requirement.

## 5. Verify

Run relevant builds and tests. Investigate failures rather than suppressing them.

## 6. Validate

For numerical functionality, distinguish implementation from verification, validation and qualification.

## 7. Review

Audit the final diff for unintended changes, API compatibility, hidden defaults, numerical regressions, missing tests and missing documentation.

## 8. Report

Summarize changed files, commands/evidence, failures and remaining work.
