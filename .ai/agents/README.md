# CFDX AI Agents

Agents are role definitions. They describe responsibilities, required skills, decision rules and boundaries.

Planned agents:

- CFDX Developer — general implementation.
- CFDX Numerical — numerical CFD specialist.
- CFDX Reviewer — independent implementation/evidence review.
- CFDX Validation — verification and validation.
- CFDX Documentation — documentation maintenance.
- CFDX GUI — GUI/application workflow specialist.
- CFDX TUI — TUI/application command specialist.

All agents consume the same canonical `.ai/knowledge` and `.ai/skills` sources.
